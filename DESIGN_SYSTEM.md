# Human Backstory Design System v1.0

## 1. System status

This document distinguishes **CANON** from **PROVISIONAL EXTENSIONS**.

Canon is supported by the approved brand identity and approved product examples. Provisional extensions may be useful in products but are not allowed to overwrite canon.

## 2. Brand core — CANON

Brand: **Human Backstory**

Editorial thesis: **Evolution Explains You**

Mother question: **Why are humans like this?**

Visual territory: Dark Psychology / Dark Philosophy.

The aesthetic should communicate introspection, discomfort, scientific seriousness, and the feeling of discovering an uncomfortable truth about oneself.

## 3. Color — CANON

| Token | Value | Meaning |
|---|---|---|
| Ground | `#0A0A0A` | primary near-black field |
| Vignette | `#060606` | edge depth / atmospheric darkening |
| Text | `#F2F2F3` | primary light typography |
| Accent | `#C0413F` | fracture / wound / uncomfortable truth |

### Red rule

One dominant red accent per composition. The accent is structural, not decoration.

No secondary red shades are canon.

## 4. Typography — CANON

Primary display:
- Family: Barlow Condensed
- Weight: 900
- Case: uppercase for wordmark, thumbnail text, evidence labels, and specified on-screen text

A body family, body size scale, line-height system, and responsive type scale are **not canon**.

## 5. Surface and texture — CANON

- Base field near black
- Fine grain
- Vignette
- Never a perfectly flat black surface
- Cold, desaturated visual finish

Exact grain density, noise seed, and opacity values are not canon unless explicitly supplied in an approved asset.

## 6. Photography — CANON

- Hard single-side light
- Chiaroscuro
- B&W or cold near-monochrome
- Deep shadow
- Psychological tension, introspection, emptiness, uncertainty
- Generous negative space

Avoid flat front light, cheerful lifestyle photography, high saturation, office-stock aesthetics, and cyberpunk clichés.

## 7. Wordmark and channel mark — CANON

The wordmark uses Barlow Condensed 900 uppercase.

The O in BACKSTORY is fractured/cut and offset with a tapered red hairline in the gap.

The standalone channel mark is the same fractured O construction and must remain legible at small sizes.

Use supplied vector assets rather than recreating the mark ad hoc.

## 8. Thumbnail system — CANON

Canvas: 1280×720.

The YouTube title and thumbnail text are separate layers:
- title explains the phenomenon
- thumbnail names the sensation, mystery, verdict, or emotional contradiction

Thumbnail text is normally 2–4 uppercase words.

Composition may alternate text-left/subject-right and subject-left/text-right. Consecutive uploads should not look like duplicated templates.

### Device logic

A device is chosen for meaning, not decoration:
- fracture → rupture / pain / tradeoff
- open loop → unfinished / rumination / no closure
- broken timeline → missing memory / temporal gap
- fragments → social or psychological breakage
- neural/constellation line → systems / cognition / mechanism

## 9. Editorial graphics — CANON

- monochromatic cold palette
- thin white diagram lines
- black fields
- restrained motion
- grain / vignette
- evidence labels: FACT / CONSENSUS / HYPOTHESIS / INFERENCE

## 10. Product extensions — PROVISIONAL until approved

The following are not canon merely because they are useful:
- landing pages
- slide templates
- UI controls
- hover/active states
- spacing scale
- body type system
- data visualization palettes
- animation duration/easing system

When needed, create them as `PROVISIONAL / DESIGN SYSTEM EXTENSION` and keep them visually subordinate to the canon system.

## 11. QA checklist

Before approval ask:
- Is the visible brand name Human Backstory?
- Is the ground near-black with texture?
- Is the subject lit with real contrast?
- Is there at most one dominant red accent?
- Does the red carry conceptual meaning?
- Is typography using the canon display face where required?
- Does the composition preserve negative space?
- Is the visual device relevant to the episode idea?
- Does the piece feel psychological/scientific rather than horror/corporate?
- Did we label any invented values as provisional?
