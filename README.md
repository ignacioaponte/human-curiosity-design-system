# Human Backstory Design System

Operational design system for **Human Backstory**, a 4 Media Company editorial brand exploring uncomfortable truths about human behavior through evolutionary psychology, neuroscience, biology, and dark philosophy.

## Purpose

This repository is the machine-readable source of truth for Claude Design and any designer, editor, developer, or AI agent creating Human Backstory products.

## Brand thesis

**Evolution Explains You.**

Mother question: **Why are humans like this?**

## Source-of-truth hierarchy

When sources conflict, use this order:

1. Approved Human Backstory Brand Identity PDF and approved visual examples
2. Canon tokens in `tokens/`
3. `CLAUDE_DESIGN.md`
4. `DESIGN_SYSTEM.md`
5. `BRAND_PRINCIPLES.md`
6. `PRODUCT_PATTERNS.md`
7. Provisional extensions

Anything not explicitly supported by canon must be labeled **PROVISIONAL / DESIGN SYSTEM EXTENSION**. Never silently invent a brand rule.

## Canon visual direction

- Dark psychology / dark philosophy
- Near-black field, never flat
- High-contrast monochrome photography
- Hard single-side light / chiaroscuro
- Generous negative space
- One red accent only
- Grain + vignette as global finishing layers
- Symbolic devices instead of generic decoration
- Scientific rigor, not horror
- Introspective unease, not spectacle

## Canon tokens

- Ground: `#0A0A0A`
- Vignette: `#060606`
- Primary text: `#F2F2F3`
- Accent red: `#C0413F`
- Display typeface: **Barlow Condensed 900**
- Display casing: uppercase where specified

## Non-negotiables

- Use **Human Backstory** as the brand name.
- Never use Human Curiosity as a visible brand name.
- Red is structural, not decorative.
- Use only one dominant red accent in a composition.
- Never place the brand mark on a perfectly flat field; grain must be present.
- Thumbnail copy should normally be 2–4 words and complement, not repeat, the YouTube title.
- Do not invent fonts, grey ramps, motion scales, hover colors, spacing systems, or product patterns and present them as canon.

## Fonts

Font binaries are intentionally not stored here. Install or provide **Barlow Condensed** through the design application or approved font workflow.
